## 二、招新意向登记字段

| 字段 | 必填 | 说明 |

| 姓名 | 是 | 与学生证一致 |

内部注册页字段与上表一致，另增密码与确认密码。提交后状态为待审核。

## 四、视觉与文件素材

| 素材 | 规格建议 | 用途 |
| --- | --- | --- |
| 标志（横版 + 图标） | SVG 优先；图标 512×512 PNG | 导航、PWA、浏览器图标 |
| 标准字「游漫社」 | 矢量 | 首屏 |
| 部门封面各 1 张 | 1600×1000，人物需可公开展示 | 部门页 |
| 首页主视觉 1 张 | 1920×1080 或插画 | 首屏氛围 |
| 往期活动照片 6–12 张 | 经压缩，单张小于 500KB | 关于页 / 活动封面 |
| 赛事海报或成绩图 | 按实际比例 | 赛事公示 |
| 制度文件 PDF | 社团章程、安全须知等 | 文件库 |
| 联系二维码 | 群二维码 PNG | 招新页 |

无标志时可暂用标准字，但会明显削弱“场面”。请勿使用来源不明的商业插画。
